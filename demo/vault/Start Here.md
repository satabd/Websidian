# Start Here

This is a small demo vault for trying the Websidian editor. Open [[Editor Playground]] to see every feature, or press **Ctrl+O** to jump to any note and **Ctrl+P** for all commands.

## Who this is for
Anyone checking how the browser editor feels next to Obsidian.
