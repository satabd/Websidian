# Glossary

## Live Preview
Obsidian's editing mode that hides Markdown syntax except where the cursor is. ^live-preview

## Wikilink
A link written `[[Note name]]`, resolved by note name anywhere in the vault. ^wikilink

## Callout
A highlighted block written `> [!type] Title`. ^callout
